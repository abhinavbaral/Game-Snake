 Game Snake 

A simple web-based Snake game that brings back the nostalgia of classic Nokia phones. Relive the experience of guiding the snake, collecting food, and trying not to crash—just like the old days.

About

Game Snake is a lightweight browser game inspired by the iconic Snake game from early Nokia devices. It focuses on simplicity, smooth gameplay, and a retro feel.

Features

* Classic Snake gameplay
* Retro-inspired design
* Easy controls
* Play directly in your browser
* No installation required

Getting Started

1. Clone the repository
2. Open the project folder
3. Launch `index.html` in your browser

Controls

* Arrow keys to move the snake
* Eat food to grow longer
* Avoid hitting walls or yourself

Inspiration

Inspired by the legendary Snake game from Nokia phones that defined mobile gaming for a generation.
